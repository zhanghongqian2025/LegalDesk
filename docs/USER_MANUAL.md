# LegalDesk 用户手册（0.2 开发版）

## 重要说明

LegalDesk 是法律工作的辅助平台，不提供或替代律师的专业判断。智能体可能遗漏事实、误读材料或生成错误引用；所有产物都应视为草稿，必须由有权限的专业人员审核后才能使用、签署、发送或提交。

## 1. 开始使用

启动 LegalDesk 后，可以先使用案件、卷宗、证据和模板等本地功能。智能体功能还需要用户显式安装兼容的 Pi CLI；应用不会静默安装它。

```bash
npm install --global @earendil-works/pi-coding-agent@0.84.1 --ignore-scripts
pi --version
```

版本必须是 `0.84.1`。如果应用显示“未安装”或“版本不匹配”，案件数据不会受影响，但智能体运行按钮应保持不可用。

安装 Pi 之前，请确认软件来源与所在组织的依赖安全策略。使用外部模型处理案件材料之前，还需确认数据地域、保留和训练政策。

## 2. 建立案件工作区

1. 在“案件管理”中创建案件。
2. 填写必要的案件名称、类型和状态；其余信息可后续补充。
3. 进入案件详情，确认页面显示的案件与准备处理的材料一致。
4. 不要把不同客户或不同案件的材料混入同一案件工作区。

删除案件可能同时删除应用受管目录内的材料。执行前先导出备份，并核对删除对象。

## 3. 导入与管理材料

1. 进入目标案件的卷宗区域。
2. 选择本地文件并导入。
3. 导入后确认文件已出现在该案件下，再决定是否删除原始副本。
4. 使用分类与备注记录材料用途、来源和核验状态。

导入文件只代表把材料纳入工作区，不代表内容已被验证或已自动完成全文识别。不要依赖文件名作为唯一证据依据。

## 4. 使用智能体

### 通用步骤

1. 进入案件详情或智能体中心。
2. 选择一个智能体，不使用无边界的通用对话替代具体任务。
3. 明确选择本次允许生成内容快照的案件材料。
4. 输入具体任务，说明期望产物、法律关系、时间范围和已知限制。
5. 在运行前确认模型提供方和材料范围。
6. 运行完成后检查“待人工审核”产物及其引用。
7. 根据原始材料逐项修改、采纳或驳回。

智能体首期不具有任何文件或命令工具。LegalDesk 仅为明确选择且通过校验的 UTF-8 文本生成内容快照（单文件 256 KiB、单次合计 1 MiB）；PDF、Office 和图片需等待后续受控提取管线。智能体不能修改原始文件，也不能自动发送或提交结果。

### 材料整理智能体

适合：文件较多、需要形成目录或排查材料缺口的案件。

建议任务写法：

```text
请按时间和材料性质整理所选文件，列出重复项、日期冲突、缺失的基础材料和需人工核验的信息。不要推断材料中没有记载的事实。
```

重点复核：文件是否分类错误、时间是否混淆、缺失项是否确实适用于本案。

### 证据审阅智能体

适合：形成证据审阅底稿或准备证据清单。

建议任务写法：

```text
请分别从真实性、合法性、关联性给出核验线索，列明证明目的、争议点和可能的补强材料。请引用所选材料，不作最终认定。
```

重点复核：材料来源、取得方式、原件情况、证明对象、程序要求及适用法律。

### 文书起草智能体

适合：在事实和诉求基本明确后形成结构化初稿。

建议任务写法：

```text
请根据所选材料起草一份民事答辩状。材料没有明确记载的姓名、日期、金额、法条和请求都标注为“待确认”，不要补造。
```

重点复核：当事人信息、事实时间线、金额、诉请、法条版本、管辖和程序期限。

## 5. 文书与证据记录

- 文书编辑区用于人工整理正式稿；智能体产物不会因生成完成而自动成为正式文书。
- 证据三性字段是工作记录，不是司法机关的证据认定。
- 保存前核对案件归属，避免把一案内容写入另一案。
- 对重要修改保留来源、审核人和时间记录。

## 6. 数据与备份

定期使用设置中的数据导出功能创建备份，并把备份放在符合组织政策的加密位置。恢复备份前：

- 确认来源可信且版本兼容；
- 先备份当前数据；
- 恢复后抽查案件、文件归属和智能体审计记录；
- 不打开来历不明的备份或材料。

“数据保存在本地”不表示模型推理必然离线。运行智能体时，选定材料可能按 Pi 的模型配置发送给外部提供方。

## 7. 故障排查

### Pi 未安装

先运行 `pi --version`。如果命令不存在，按本手册显式安装固定版本，或联系组织管理员提供审核过的可执行文件。

### Pi 版本不兼容

LegalDesk 0.2 只支持 `0.84.1`。不要通过绕过版本检查强行运行；按组织流程安装兼容版本。

### 智能体无法读取文件

确认文件已经导入当前案件，并在本次运行中被明确选择。其他案件或应用受管目录以外的路径不会开放。

### 运行失败或中断

保留运行记录和错误摘要，重新检查材料和任务说明。部分输出仍是未完成草稿，不能视为已审核产物。

### 发现安全问题

停止处理敏感材料，不要在公开 Issue 中粘贴案件内容、密钥或利用细节，按 [SECURITY.md](../SECURITY.md) 的方式报告。

## 8. 当前限制

- 当前为开发版本，不用于未经机构评估的正式生产案件处理。
- 完整的团队权限、集中审计、静态加密和离线模型交付仍在规划中。
- 支持的文件类型与内容解析能力以应用实际提示为准。
- 法律检索、法规时效校验和外部系统提交未包含在首期智能体权限中。
